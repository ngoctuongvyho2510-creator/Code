# ModifyWrap 3D S4 Demo — Codex Instructions

## Project purpose

This repository contains the frontend code for the ModifyWrap 3D S4 Demo.

The project will eventually include:

- A 3D Audi S4 configurator
- Vinyl wrap materials and finishes
- Chrome delete
- Window tint
- Paint protection film
- Ceramic coating
- Caliper paint
- Powder coating
- Customer artwork and decal placement
- Five-angle design snapshots
- Repeated ModifyWrap watermarks
- Save Design by Email
- Request for Quote flow

Build the project incrementally. Do not attempt to implement the entire product in one task.

## Current technology

- Vite
- React
- TypeScript
- ESLint
- CSS

Do not install additional packages unless the user explicitly approves them.

## Repository rules

1. Only modify files required for the current task.
2. Do not rename existing files or folders unless explicitly instructed.
3. Do not delete files unless explicitly instructed.
4. Do not move files unless explicitly instructed.
5. Do not change the application architecture without approval.
6. Do not add a backend, database, authentication, email provider, payment system, or external API unless explicitly requested.
7. Do not add Three.js or 3D libraries until explicitly requested.
8. Do not add placeholder business features that were not requested.
9. Do not replace working code merely for stylistic preference.
10. Keep each task small, reviewable, and reversible.

## Verification

After every implementation task, run:

```bash
npm run build
npm run lint
```

A task is not complete if either command fails.
